# Gap to demo

A claim is not done until a stranger can open a page.

- A row counts only if the asker is not Jani, @JanSol0s, AgentMindCloud, a fleet bot, or a test.
- The page must load with no local shell and no sign-in.
- localhost, 127.0.0.1, and a markdown pack are not a demo.
- DEMO READY is sent only when that page returns a real document.
- Closed classes are not rebuilt: download-page RPM HTTP 403, and usage with no per-chat split.
- No pay, no post, no merge of a product repo, no new bot from this file.
